# Forma UI Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Pixi's shared look (tokens, glass, buttons, slider, swatch pair, home screen pattern) out of `style.css` into a self-contained `forma-ui/` folder that Pixi consumes, with zero visual change.

**Architecture:** `forma-ui/` holds `tokens.css`, `components.css`, `home.css`, a style guide page and a README, and never references Pixi. Pixi links those files before `style.css`. The floating workspace's glass and ghost looks, which today come from long Pixi-ID selector lists, come from plain Forma classes that `applyLayout()` adds when the layout is floating. A computed-style snapshot script proves nothing changed after every task.

**Tech Stack:** Plain CSS + ES modules, no build step. Tests: `node --test` (Node 22). Snapshot tool: Node 22 + Google Chrome over the DevTools protocol (no npm dependency).

**Spec:** `docs/superpowers/specs/2026-10-04-forma-ui-design.md`. Read it first.

## Global Constraints

- **Zero visual change.** After every task, `node scripts/style-snapshot.mjs diff test-output/baseline test-output/current` prints `no differences`. A difference is a bug, never "close enough".
- `forma-ui/` never references Pixi: no Pixi IDs, no `.workspace-screen`, no `data-layout`, no `style.css`, no `js/`, no `../` paths. This includes comments.
- Load order in every page: `forma-ui/tokens.css`, `forma-ui/components.css`, `forma-ui/home.css` (index.html only), then `style.css`.
- Allowed per-app token overrides: `--color-accent`, `--color-accent-strong`, `--color-accent-soft` only. Pixi overrides none today.
- Forma UI has no `prefers-color-scheme` query. Themes: dark on `:root`, light on `:root[data-theme="light"]`.
- Icon font: Material Symbols Outlined, weight 300.
- When a Pixi rule needs to stop applying to an element that now has a Forma class, append `:not(:where(.<forma-class>))` to that Pixi selector. The `:where()` keeps the selector's specificity unchanged, so nothing else in the cascade shifts.
- No new npm dependencies. No behavior change, so no `docs/specs/*` edits.
- Local server for snapshots: `python3 -m http.server 8765` from the repo root (start it in the background yourself; don't ask).
- Branch: `forma-ui` (already exists, holds the spec). Commit after each task. End commit messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

// Computed-style snapshots of Pixi's screens, for refactors that must not
// change how anything looks (the Forma UI extraction). No dependencies:
// drives Google Chrome over the DevTools protocol with Node 22's built-in
// WebSocket and fetch.
//
//   node scripts/style-snapshot.mjs capture <out-dir> [base-url]
//   node scripts/style-snapshot.mjs diff <dir-a> <dir-b>
//
// capture needs a local server (python3 -m http.server 8765 in the repo
// root). Per theme and window size it starts a fresh Chrome profile (so
// IndexedDB starts empty) and writes <theme>-<w>x<h>-<state>.json (the
// listed computed properties of every element, plus ::before/::after) and
// a .png. Elements are keyed by DOM index path, so class renames don't
// change keys. diff lists every difference and exits 1 if there are any.
import { spawn } from 'node:child_process';
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';

const CHROME = '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
const THEMES = ['dark', 'light'];
const SIZES = [[1180, 820], [390, 844]];
const PROPS = [
  'display', 'position', 'top', 'right', 'bottom', 'left', 'z-index', 'isolation',
  'width', 'height', 'min-width', 'min-height', 'max-width', 'max-height', 'box-sizing',
  'margin-top', 'margin-right', 'margin-bottom', 'margin-left',
  'padding-top', 'padding-right', 'padding-bottom', 'padding-left',
  'flex-direction', 'flex-wrap', 'flex-grow', 'flex-shrink', 'flex-basis', 'order',
  'align-items', 'justify-content', 'row-gap', 'column-gap', 'grid-template-columns',
  'overflow-x', 'overflow-y',
  'color', 'background-color', 'background-image', 'background-size', 'background-position',
  'border-top-width', 'border-right-width', 'border-bottom-width', 'border-left-width',
  'border-top-style', 'border-right-style', 'border-bottom-style', 'border-left-style',
  'border-top-color', 'border-right-color', 'border-bottom-color', 'border-left-color',
  'border-top-left-radius', 'border-top-right-radius', 'border-bottom-right-radius', 'border-bottom-left-radius',
  'box-shadow', 'opacity', 'visibility', 'transform', 'translate', 'filter', 'backdrop-filter',
  'font-family', 'font-size', 'font-weight', 'line-height', 'letter-spacing', 'text-align',
  'cursor', 'pointer-events', 'touch-action',
  'outline-style', 'outline-width', 'outline-color', 'outline-offset',
  'content', 'object-fit', 'image-rendering', 'aspect-ratio', 'transition-property', 'transition-duration',
];

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

async function openChrome() {
  const port = 9300 + Math.floor(Math.random() * 500);
  const profile = fs.mkdtempSync(path.join(os.tmpdir(), 'pixi-snap-'));
  const proc = spawn(CHROME, [
    '--headless=new', `--remote-debugging-port=${port}`, `--user-data-dir=${profile}`,
    '--hide-scrollbars', 'about:blank',
  ], { stdio: 'ignore' });
  let target;
  for (let i = 0; i < 50 && !target; i++) {
    await sleep(200);
    try {
      target = (await (await fetch(`http://127.0.0.1:${port}/json`)).json()).find((t) => t.type === 'page');
    } catch {}
  }
  if (!target) {
    proc.kill();
    throw new Error('Chrome did not start');
  }
  const ws = new WebSocket(target.webSocketDebuggerUrl);
  await new Promise((resolve, reject) => {
    ws.addEventListener('open', resolve);
    ws.addEventListener('error', reject);
  });
  let nextId = 0;
  const pending = new Map();
  const listeners = [];
  ws.addEventListener('message', (e) => {
    const msg = JSON.parse(e.data);
    if (msg.id && pending.has(msg.id)) {
      const { resolve, reject } = pending.get(msg.id);
      pending.delete(msg.id);
      if (msg.error) reject(new Error(msg.error.message));
      else resolve(msg.result);
    } else if (msg.method) {
      for (const l of [...listeners]) l(msg);
    }
  });
  const send = (method, params = {}) => new Promise((resolve, reject) => {
    const id = ++nextId;
    pending.set(id, { resolve, reject });
    ws.send(JSON.stringify({ id, method, params }));
  });
  const waitEvent = (method) => new Promise((resolve) => {
    const l = (m) => {
      if (m.method !== method) return;
      listeners.splice(listeners.indexOf(l), 1);
      resolve(m.params);
    };
    listeners.push(l);
  });
  const close = () => {
    ws.close();
    proc.kill();
    fs.rmSync(profile, { recursive: true, force: true });
  };
  return { send, waitEvent, close };
}

async function evaluate(page, expression) {
  const { result, exceptionDetails } = await page.send('Runtime.evaluate', { expression, awaitPromise: true, returnByValue: true });
  if (exceptionDetails) throw new Error(exceptionDetails.exception?.description ?? exceptionDetails.text);
  return result.value;
}

async function settle(page) {
  await evaluate(page, 'document.fonts.ready.then(() => new Promise((r) => requestAnimationFrame(() => requestAnimationFrame(r))))');
  await sleep(500);
}

async function go(page, url) {
  const loaded = page.waitEvent('Page.loadEventFired');
  await page.send('Page.navigate', { url });
  await loaded;
  await settle(page);
}

async function setHash(page, hash) {
  await evaluate(page, `location.hash = ${JSON.stringify(hash)}`);
  await settle(page);
}

async function waitFor(page, expression, ms = 8000) {
  const end = Date.now() + ms;
  while (Date.now() < end) {
    if (await evaluate(page, expression)) return;
    await sleep(100);
  }
  throw new Error(`timed out waiting for ${expression}`);
}

const DUMP = `(() => {
  const PROPS = ${JSON.stringify(PROPS)};
  const key = (el) => {
    const parts = [];
    for (let e = el; e !== document.body; e = e.parentElement) {
      parts.unshift(e.tagName.toLowerCase() + ':' + [...e.parentElement.children].indexOf(e) + (e.id ? '#' + e.id : ''));
    }
    return parts.join('/');
  };
  const read = (cs) => Object.fromEntries(PROPS.map((p) => [p, cs.getPropertyValue(p)]));
  const out = {};
  for (const el of document.body.querySelectorAll('*')) {
    const k = key(el);
    const r = el.getBoundingClientRect();
    out[k] = { rect: [r.x, r.y, r.width, r.height].map((n) => Math.round(n * 10) / 10).join(','), ...read(getComputedStyle(el)) };
    for (const pseudo of ['::before', '::after']) {
      const cs = getComputedStyle(el, pseudo);
      if (cs.content !== 'none' && cs.content !== 'normal') out[k + pseudo] = read(cs);
    }
  }
  return out;
})()`;

async function capture(outDir, base) {
  fs.mkdirSync(outDir, { recursive: true });
  for (const theme of THEMES) {
    for (const [width, height] of SIZES) {
      const page = await openChrome();
      const tag = `${theme}-${width}x${height}`;
      try {
        await page.send('Page.enable');
        await page.send('Runtime.enable');
        await page.send('Emulation.setDeviceMetricsOverride', { width, height, deviceScaleFactor: 1, mobile: false });
        await page.send('Emulation.setEmulatedMedia', { features: [{ name: 'prefers-reduced-motion', value: 'reduce' }] });
        await page.send('Page.addScriptToEvaluateOnNewDocument', {
          source: `try { localStorage.setItem('pixi-theme-preference', '${theme}'); } catch (e) {}`,
        });
        const snap = async (state) => {
          const data = await evaluate(page, DUMP);
          fs.writeFileSync(path.join(outDir, `${tag}-${state}.json`), JSON.stringify(data));
          const { data: png } = await page.send('Page.captureScreenshot', { format: 'png' });
          fs.writeFileSync(path.join(outDir, `${tag}-${state}.png`), Buffer.from(png, 'base64'));
          console.log(`${tag}-${state}`);
        };
        await go(page, new URL('index.html#/', base).href);
        await snap('gallery-empty');
        await setHash(page, '#/new');
        await snap('new-canvas');
        await evaluate(page, `document.getElementById('create-canvas-button').click()`);
        await waitFor(page, `location.hash.startsWith('#/project/')`);
        await settle(page);
        await sleep(800);
        await snap('workspace');
        await evaluate(page, `document.getElementById('more-button').click()`);
        await settle(page);
        await snap('workspace-more-open');
        await setHash(page, '#/');
        await snap('gallery-populated');
        await go(page, new URL('lib/pixi-embed-example.html', base).href);
        await sleep(800);
        await snap('embed');
      } finally {
        page.close();
      }
    }
  }
}

function diff(dirA, dirB) {
  let count = 0;
  for (const file of fs.readdirSync(dirA).filter((f) => f.endsWith('.json')).sort()) {
    const fileB = path.join(dirB, file);
    if (!fs.existsSync(fileB)) {
      console.log(`${file}: missing in ${dirB}`);
      count++;
      continue;
    }
    const a = JSON.parse(fs.readFileSync(path.join(dirA, file), 'utf8'));
    const b = JSON.parse(fs.readFileSync(fileB, 'utf8'));
    for (const k of new Set([...Object.keys(a), ...Object.keys(b)])) {
      if (!a[k] || !b[k]) {
        console.log(`${file} ${k}: only in ${a[k] ? dirA : dirB}`);
        count++;
        continue;
      }
      for (const p of Object.keys(a[k])) {
        if (a[k][p] !== b[k][p]) {
          console.log(`${file} ${k}\n    ${p}: ${a[k][p]}  ->  ${b[k][p]}`);
          count++;
        }
      }
    }
  }
  console.log(count ? `${count} difference(s)` : 'no differences');
  process.exitCode = count ? 1 : 0;
}

const [command, ...args] = process.argv.slice(2);
if (command === 'capture' && args[0]) {
  await capture(args[0], args[1] ?? 'http://127.0.0.1:8765/');
} else if (command === 'diff' && args[1]) {
  diff(args[0], args[1]);
} else {
  console.error('usage: node scripts/style-snapshot.mjs capture <out-dir> [base-url]\n       node scripts/style-snapshot.mjs diff <dir-a> <dir-b>');
  process.exit(2);
}

// checks, like test/floating-layout-css.test.js: they read the files

import { test, describe } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync } from 'node:fs';

const read = (path) => readFileSync(new URL(`../${path}`, import.meta.url), 'utf8');
const strip = (css) => css.replace(/\/\*[\s\S]*?\*\//g, '');

function block(css, selector) {
  const start = css.indexOf(`${selector} {`);
  assert.notEqual(start, -1, `${selector} not found`);
  return css.slice(start, css.indexOf('}', start));

- [ ] **Step 3: Write `forma-ui/README.md`**

```markdown
# Forma UI

Forma's shared design system: the frosted-glass look of Forma's apps
(Pixi, Lines), as plain CSS with no build step. Open `index.html` for
every component in every state, in both themes.

## Files

| File | What it holds |
|---|---|
| `tokens.css` | Colours, glass, floating layout, ghost button, icon sizes, home scrim. Dark on `:root`, light on `:root[data-theme="light"]`. |
| `components.css` | `.glass`, `.glass-pill`, `.glass-circle`, `.ghost-button` (+ `.ghost-text`), `.primary-button`, `.slider`, `.swatch-pair` |
| `home.css` | The home screen pattern: `.home-screen`, `.home-backdrop`, `.home-hero`, `.home-wordmark`, `.home-recents`, `.home-grid`, `.home-tile*`, `.home-empty-state` |
| `index.html` | The style guide |

## Using it in an app

Link the files before the app's own stylesheet:

    <link rel="stylesheet" href="forma-ui/tokens.css">
    <link rel="stylesheet" href="forma-ui/components.css">
    <link rel="stylesheet" href="forma-ui/home.css">
    <link rel="stylesheet" href="app.css">

- **Themes:** set `data-theme="light"` or `"dark"` on `<html>`. Forma UI
  doesn't follow the system setting by itself: the app resolves the
  user's preference (including "system") and sets the attribute, ideally
  in a small classic script in `<head>` so there's no flash.
- **Icons:** Material Symbols Outlined, weight 300, from Google Fonts.
- **Glass elements must be positioned** (`relative`, `absolute` or
  `fixed`): the blur is an absolute `::before` layer. It's on `::before`
  because `backdrop-filter` would make the card the containing block for
  fixed-position descendants such as popovers.
- **Density:** ghost buttons and glass circles size from
  `--rail-button-size` (fallback 2.75rem). The app may set it on a
  container.
- **Specificity:** every Forma rule is a single class. If an app rule
  must stop applying to an element that carries a Forma class, append
  `:not(:where(.forma-class))` to the app's selector rather than raising
  Forma's.

## Tokens

- Colour: `--color-bg`, `--color-surface`, `--color-surface-alt`,
  `--color-track`, `--color-border`, `--color-text`,
  `--color-text-secondary`, `--color-text-tertiary`, `--color-text-muted`,
  `--color-text-subtle`, `--color-text-subtle-2`, `--color-accent`,
  `--color-accent-strong`, `--color-accent-soft`, `--color-danger`,
  `--color-success`, `--color-overlay`, `--color-overlay-soft`
- Glass: `--glass-tint`, `--glass-tint-hover`, `--glass-border`,
  `--glass-highlight`, `--glass-blur`
- Floating layout: `--float-radius`, `--float-gap`, `--float-edge`,
  `--float-shadow`
- Ghost button: `--ghost-hover`, `--ghost-on-bg`, `--ghost-on-fg`
- Icon size: `--icon-size-xs`, `--icon-size-s`, `--icon-size-m`,
  `--icon-size-l`, `--icon-size-xl`
- Home: `--home-scrim-inner`, `--home-scrim-outer`

`--glass-blur` may also be set on a single glass element to tune its blur.

## Allowed overrides

An app may override only these, on `:root` and `:root[data-theme="light"]`:

- `--color-accent`
- `--color-accent-strong`
- `--color-accent-soft`

Everything else stays identical across Forma's apps. The wordmark text
and the home backdrop image are markup the app supplies.

## Status

Lives inside the Pixi repo for now. Once it's finished, it moves to its
own repo and each app vendors a pinned copy.
```
