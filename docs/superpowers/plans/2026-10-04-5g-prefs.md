# 5g Prefs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Prefs sheet (from More) with independent Tools side / Panels side, pinned cards and auto-hide while drawing, persisted in localStorage, standalone app only.

**Architecture:** Pure `js/prefs.js` (defaults, normalize, load/save, apply as `data-*` attributes on `#screen-workspace`); `js/prefs-sheet.js` wires a native `<dialog>` in `index.html`. CSS maps the side attributes onto the existing slot variables (logical insets only). `clearInsets` takes an explicit side per card so Fit/selection bar follow the sides.

**Tech Stack:** vanilla ES modules, CSS custom properties, `node --test`.

Design: `docs/superpowers/specs/2026-10-04-5g-prefs-design.md`.

## Global Constraints

- No build step, no new dependencies.
- Floating CSS never sets physical `left:`/`right:` (guarded by `test/floating-layout-css.test.js`).
- Standalone only: nothing in `lib/pixi.js` changes; prefs are wired from `js/app.js`.
- Storage key `pixi-prefs`; every storage access in try/catch.
- Same-side order from the edge: tool rail, mini-rail, cards. No re-fit on a side change.
- Auto-hide tools: pencil, eraser, brush, line, rectangle. Default off.
- Touch targets ≥ 44px; switches are `input[type=checkbox][role=switch]`.
